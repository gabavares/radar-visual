# Vocabulário-semente

Lista de termos que a pesquisa monitora. Não é uma lista fechada: o ciclo mensal
adiciona o que a expansão descobrir.

Cada termo é pesquisado no nome principal e nos apelidos, porque a mesma coisa
tem nome diferente em cada comunidade e é assim que o time perde a referência.

Status dos blocos: 1 e 2 prontos para validação do Gab. Blocos 3 a 6 esboçados,
a serem completados na fase 2.

---

## Bloco 1: Técnicas e efeitos

O que se faz com a imagem. É onde mora o pixel stretch e onde o designer
consegue sair da ficha direto para o software.

| Termo | Apelidos e variantes |
|---|---|
| Pixel stretch | pixel drag, smear, slit scan |
| Pixel sorting | glitch sorting, datamoshing sort |
| Halftone | dot matrix, ben-day dots, moiré print |
| Dithering | 1-bit, bayer dither, floyd-steinberg |
| Chrome | liquid chrome, liquid metal, mercury type |
| Glitch | datamosh, corruption, databending |
| Risograph | riso print, spot color misregistration |
| Duotone | tritone, split tone |
| Motion blur | long exposure, light trail, smear frame |
| Anamorphic flare | lens flare, bloom, halation |
| Scanlines | CRT, VHS artifact, interlace |
| Xerox degradation | photocopy, generation loss, toner blowout |
| Solarização | efeito Sabattier, inversão parcial |
| Displacement map | warp, liquify, mesh distortion |
| Caustics | refração, water light, dispersion |
| Trapped print | ink trap, overprint, registration shift |

## Bloco 3: Tipografia

A esboçar. Sementes iniciais: serifada de display em revival, condensada
extrema, tipo variável, letra desenhada à mão, blackletter contemporânea,
tipografia cinética, tipo esticado, wordmark minúsculo.

## Bloco 4: Cor e paleta

A esboçar. Sementes iniciais: cores dessaturadas, alta saturação digital,
paletas monocromáticas, cor institucional saturada, gradiente de malha,
duotom de marca, neutros quentes.

## Bloco 5: Materialidade e render

A esboçar. Sementes iniciais: glassmorphism, claymorphism, inflável,
cerâmica, iridescente, borracha, tecido 3D, plástico soft touch,
metal escovado, vidro fosco.

## Bloco 6: Fotografia e direção de arte

A esboçar. Sementes iniciais: flash direto, grão de filme, câmera
descartável, candid editorial, still life saturado, fotografia de produto
sem cenário, sobreposição de texto em foto.
